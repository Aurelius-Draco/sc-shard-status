# Security and privacy

Found a way the app could leak something about a player, let someone else into the dashboard, or run something it shouldn't? Please tell me privately first, not in a public issue.

## How to report it

- **On GitHub:** open the repo's **Security** tab and choose **Report a vulnerability**. Only I can see it.
- **On Discord:** send a direct message to Aurelius_Draco (join through https://discord.gg/8kH5pfHYbe).

Say what you found, how to make it happen, and which version you're on. Leave out real players' handles, and crop the in-game QR code out of any screenshots.

I'll reply as soon as I can, fix it in the next release, and credit you in the changelog if you'd like.

## Which versions get fixes

Only the latest release. The app offers updates itself, so updating is the fix.
